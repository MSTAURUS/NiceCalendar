## 3. Отображение на панели

- Дата, время или оба; порядок настраивается.
- Форматы даты/времени — `strftime` + пресеты.
- Отдельные шрифты для даты и времени.
- Фон — прозрачный.
- **Ориентация** — по `size-allocate`:
  `width >= height` → горизонтальная, иначе вертикальная.
  При смене: `box.set_orientation()` + `label.set_angle(270)`.
  Публичный `PanelWidget.set_orientation()` — для тестов.
- **Обновление:**
  - раз в секунду при включённых секундах, иначе раз в минуту;
  - двухфазный ре-align к границе;
  - при смене `show-seconds` таймер пересоздаётся.
- **Tooltip** — `%A, %d %B %Y, %H:%M:%S` по локали.
- **Клики:** левый — открыть/закрыть поповер; правый — меню
  (Свойства / О программе); средний/колесо — v2.
- Несколько экземпляров — независимые.

## 4. Поповер

### 4.1. Общий вид
- Стиль Windows 10.
- `Gtk.Popover`, привязанный к виджету панели.
- Закрытие: клик вне, `Esc`, повторный левый клик.
- Анимация и fallback на `Gtk.Window` — v2.

### 4.2. Структура
1. Крупное время (отдельный шрифт).
2. День недели, месяц прописью, год.
3. Разделитель (1 px, alpha ~15 %).
4. Шапка: месяц + год слева; `‹` `›` справа.
5. Сетка 7×7: шапка дней недели (`%a` локали) + 6 строк дат.

### 4.3. Заполнение сетки
- Соседние месяцы видны, alpha 45 %.
- Клик по дню соседнего месяца — переключает месяц, **не ставит рамку
  выбора**.
- Сетка фиксированной высоты (6 строк).
- Опция «Показывать дни соседних месяцев» (вкл).

### 4.4. Выделение
- «Сегодня» — 1 px скруглённая рамка акцентного цвета.
- Рамка выбора — 1 px прямоугольная:
  - ставится по клику или `Enter`;
  - снимается повторным кликом / `Enter`;
  - только одна дата;
  - не ставится на «сегодня» и на дни соседних месяцев;
  - сбрасывается при закрытии поповера.

### 4.5. Навигация

| Клавиша | Действие |
|---------|----------|
| `←` / `→` | ±1 день |
| `↑` / `↓` | ±7 дней |
| `PageUp` / `PageDown` | ±1 месяц |
| `Home` | К сегодня |
| `Enter` / `Space` | Выбрать/снять |
| `Esc` | Закрыть |
| `Tab` | По кнопкам |

- Клавиши обрабатываются на `Gtk.Popover` (всплывают от ячейки).
- При выходе за месяц страница перелистывается, фокус остаётся на дате.
- Состояние фокуса — `Popup._focused_date`; переживает `_rebuild()`.

### 4.6. Обновление
- Раз в минуту: время в шапке + проверка полуночи (`_last_day`).
- При закрытии таймер отключается.

### 4.7. Внешний вид — цвета

Реализует `nicecalendar/theme.py`.

- Фон: `theme` (не трогаем) или `custom`
  (`popover { background-color; color: autoconstrast; }`).
- Автоконтраст: `Y = 0.299·R + 0.587·G + 0.114·B`, порог 128.
- «Сегодня» и рамка выбора: акцент темы **или** свой.
  Акцент читается CSS-пробой (`@theme_selected_bg_color`),
  fallback `#3584e4`.
- CSS-провайдер — per-instance (`popover.get_style_context()`),
  не на `Gdk.Screen`.
- Реакция на `notify::gtk-theme-name`.
- Выходные — v2.

## 5. Настройки

`Gtk.Dialog` + `Gtk.Notebook`, живое применение, кнопки
«Сбросить» / «Закрыть».

### 5.1. «Панель»

| Параметр               | Тип                     | Умолчание  |
|------------------------|-------------------------|------------|
| Показывать дату        | чекбокс                 | вкл        |
| Показывать время       | чекбокс                 | вкл        |
| Порядок                | Дата–Время / Время–Дата | Дата–Время |
| Разделитель            | ввод                    | пробел     |
| Формат даты            | пресеты + `strftime`    | `%d.%m.%Y` |
| Формат времени         | пресеты + `strftime`    | `%H:%M`    |
| Показывать секунды     | чекбокс                 | выкл       |
| 12-часовой формат      | чекбокс                 | выкл       |
| Показывать день недели | чекбокс                 | выкл       |

Правила: чекбоксы «секунды»/«12ч»/«день недели» действуют только на
пресеты; при выборе «Свой формат» соответствующие чекбоксы
дизейблятся; если дата или время выключены — разделитель не
показывается.

Пресеты даты: `%d.%m.%Y`, `%d/%m/%Y`, `%Y-%m-%d`, `%d %b`, `%A, %d %B`.
Пресеты времени: `%H:%M`, `%H:%M:%S`, `%I:%M %p`, `%I:%M:%S %p`.

### 5.2. «Шрифты»
FontChooser для даты, времени, сетки, крупного времени в поповере.
Умолчание — пустая строка (= системный шрифт панели).

### 5.3. «Календарь»

| Параметр                        | Тип                        | Умолчание      |
|---------------------------------|----------------------------|----------------|
| Первый день недели              | Локаль / Пн / Вс / Сб      | Локаль         |
| Фон                             | Системная тема / Свой цвет | Системная тема |
| Свой цвет фона                  | color-picker               | `#ffffff`      |
| Цвет «сегодня»                  | Акцент / Свой              | Акцент         |
| Свой цвет «сегодня»             | color-picker               | `#3584e4`      |
| Цвет рамки выбора               | Акцент / Свой              | Акцент         |
| Свой цвет выбора                | color-picker               | `#3584e4`      |
| Показывать дни соседних месяцев | чекбокс                    | вкл            |

### 5.4. «Разное»

| Параметр           | Тип     | Умолчание |
|--------------------|---------|-----------|
| Показывать tooltip | чекбокс | вкл       |

### 5.5. Хранение
- Канал `xfce4-panel`, путь `/plugins/plugin-N/<param>`.
- Дефолты не пишутся до изменения.
- «Сбросить» удаляет все ключи плагина.
- Без Xfconf — fallback на in-memory + предупреждение.

### 5.6. Не делаем в v1
Профили, экспорт, ручное позиционирование, горячие клавиши,
внешние календари, уведомления, выделение выходных, fallback на
`Gtk.Window`.

## 6. Технические детали

### 6.1. Общее
- Календарь — `Gtk.Grid` + stdlib `calendar`.
- Часовой пояс — `datetime.now().astimezone()`.
- HiDPI — логические пиксели, тест 100 % / 200 %.
- Логирование: `logging`, `WARNING`; `NICECALENDAR_DEBUG=1` → `DEBUG`.

### 6.2. UI через GtkBuilder

Все интерфейсы — в `.ui` (XML), не в коде:
`panel.ui`, `popup.ui`, `settings.ui`.

Загрузка — `Gtk.Builder.add_from_file(path)`,
`builder.set_translation_domain("nicecalendar")`.

Поиск `.ui` — по списку кандидатов (первый существующий):
1. `<repo>/ui/<name>`;
2. `~/.local/share/nicecalendar/ui/<name>`;
3. `/usr/share/nicecalendar/ui/<name>`.

При отсутствии — `log.exception` + `sys.exit(1)`.

### 6.3. Модель процессов
- Отдельный Python-процесс на каждый экземпляр плагина.
- Завершение по `destroy` `Gtk.Plug`.
- Плавный выход по `SIGTERM` / `SIGINT`.
- `uninstall.sh` вызывает `pkill -f "/nicecalendar/plugin.py"`.

### 6.4. Локаль и дни недели
- `%a` через `datetime.strftime`, не `calendar.day_abbr`.
- `locale.setlocale(locale.LC_TIME, "")` при старте (только `LC_TIME`).
- Месяцы — `strftime('%B')`.
- Ручное переопределение первого дня недели меняет порядок, но не
  названия.

### 6.5. Архитектурные требования для порта

**Чистые модули без GTK:**
- `calendar_grid.py`
- `utils.py`
- `config.py` (GObject, но не Gtk)

Правила: не импортировать `gi.repository.Gtk`; без `*args`,
`**kwargs`, метаклассов, декораторов-as-architecture, `setattr`,
`getattr`, множественного наследования.

**GTK-зависимые:**
`plugin.py`, `panel_widget.py`, `popup.py`, `settings_dialog.py`,
`theme.py`.

UI — только `.ui`. Тесты покрывают чистую логику без GTK.

### 6.6. Тема и CSS

`theme.py`:
- `theme_accent_rgb()` — читает `@theme_selected_bg_color`,
  fallback `#3584e4`.
- `build_popup_css(config)` — CSS для одного экземпляра.
- `apply_popup_css(popover, config, prev)` — ставит провайдер на
  `StyleContext` поповера, возвращает для удаления при следующем
  вызове.

Классы CSS: `nicecalendar-day`, `-adjacent`, `-today`, `-selected`,
`nicecalendar-weekday-header`, `nicecalendar-big-time`.

### 6.7. Фокус и клавиатура

- `Popup._focused_date: date | None` — единственный источник истины.
- `Popup._day_dates: list[date]` — параллельно `_day_buttons`.
- При `_rebuild()`: фокус → `_focused_date`, иначе «сегодня», иначе
  первое число отображаемого месяца.
- Клавиши обрабатываются на `Gtk.Popover`.
- `Enter` / `Space` — стандартный `Gtk.Button`.
- `Tab` — стандартный focus-chain.

## 11. Установка

`install.sh` копирует:

- `nicecalendar/` → `~/.local/lib/nicecalendar/`
- `ui/*.ui` → `~/.local/share/nicecalendar/ui/`
- `nicecalendar.desktop` → `~/.local/share/xfce4/panel/plugins/`
- `nicecalendar.svg` → `~/.local/share/icons/hicolor/scalable/apps/`
- `po/*.po` → `~/.local/share/locale/<lang>/LC_MESSAGES/nicecalendar.mo`
- скрипт `nicecalendar` → `~/.local/bin/`

`uninstall.sh` удаляет всё вышеперечисленное, чистит xfconf,
завершает процессы `pkill -f "/nicecalendar/plugin.py"`.

## 12. Тестирование

**Юнит-тесты** (`tests/`, без GTK):
сетка, `weekday_order`, `header_month`, `shift_month`, `is_same_day`,
пресеты `strftime`, автоконтраст, hex-парсинг, `format_panel_text`.

**Проверка отсутствия GTK:**
`TestNoGtkImport` для `calendar_grid.py` и `utils.py`.

**Ручное:**
Ubuntu 24.04 + XFCE 4.18; светлая/тёмная темы; панель сверху/снизу/
слева/справа (переключение без перезапуска); 100 % и 200 % DPI;
несколько экземпляров (разные фоны — без конфликта); мультимонитор;
`en_US.UTF-8` и `ru_RU.UTF-8`; смена системной темы — перекраска
поповера; корректное завершение после удаления; `pkill` не находит
процессов после `uninstall.sh`.
